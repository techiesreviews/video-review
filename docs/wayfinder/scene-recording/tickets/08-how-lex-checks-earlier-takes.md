## Question

If Lex thinks an earlier take of a scene went better, where does he check it? The Prompter must not play video.

## Resolution (2026-11-13)

Options put to Lex: (1) the video-review page after the session, (2) the main screen (the second window the Prompter
already opens links on) while recording, (3) both, 1 first. Lex: "3".

- First: the video-review page shows each scene with its takes; Lex plays them, stars the best, and the best takes
  feed the rough cut. See [How takes show up in video-review](07-how-takes-show-up-in-video-review.md).
- Later: clicking an older take's dot on the Prompter's left-edge rail plays it on the main screen, with the
  Prompter itself unchanged. It waits for the answers on where takes live
  ([Where takes live and how they are named](06-where-takes-live-and-how-they-are-named.md)).
